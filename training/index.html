How to use this pathway

New to accessibility at DOT? Start with Section 1 and work through the lessons in order — each one builds on the last. Already comfortable with the basics? Jump to the testing skill or language integration you need. Supervisors and leads can use the sections as an onboarding roadmap.

Every lesson links to the matching How-to Test guide or Developer Resource on this site, so the training and the reference material stay in step.
