How to use this pathway

New to accessibility testing at DOT? Start with Section 1 and work through the lessons in order — each one builds on the last. Already comfortable with the basics? Jump to the testing skill you need. Leads can use the sections as an onboarding roadmap for new QA analysts.

The lessons line up with the How-to Test guides on this site, so you can move straight from a lesson to the step-by-step test for a component.
