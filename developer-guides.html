This section is where developers set up automated accessibility testing, implement accessible components, and review code for accessibility before it merges.

Use the axe-core integration guides to add automated scans to a Java, Python, C#, Angular, or .NET project, or to your IDE with the IntelliJ Axe Linter. Use the CI/CD guide to run those scans automatically as part of your build pipeline. The Accessible Components guide has implementation patterns — markup, ARIA, and keyboard behavior — for common UI components like forms, modals, and navigation. And the Accessibility in Code Review checklist covers what to manually check for — heading structure, labels, focus styles, alt text — when you're reviewing a pull request.
